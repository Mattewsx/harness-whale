# 皮肤素材

20 亲密度解锁见习魔女；40 解锁长袖睡衣，60 解锁连帽家居服。三张 4×3 PNG
各有十个使用姿态，最后两格为备用待机；顺序与 main/whale_ui.c 一致。
所有形象保留小蓝蝴蝶结，去掉王冠。maid-companion.png 是默认互动六姿态的 3×2 原图。

素材为本次对话中已完成的生图结果，使用项目现有形象作参考，并按用户反馈调整服装和蝴蝶结大小。
角色来源仍见 LICENSES/ATTRIBUTION.txt。网络搜索用于服装方向参考，未采用的水手服、
咖啡店设计稿不放入这个素材目录。

运行 tools/make_whale_outfits.py 重建原生 196 像素 RGB565A8 和逐帧元数据。仅裁掉
完全透明的边缘，使用保存的偏移还原到原画布，不再放大显示。三套各十个姿态共
2,755,957 字节。魔女尖帽姿态直接从原图适配尺寸并保留台词间距，不增加运行时
图像缓冲区或云端服务。

衣橱选中即可预览未解锁皮肤，确认仅能穿已拥有的皮肤；再次确认已穿皮肤恢复默认女仆装。
浏览预览不会改写已穿皮肤，会话中的工作状态始终使用默认立绘。

衣橱四个图标分别为女仆裙、尖帽魔女袍、纽扣睡衣和连帽连体服。运行
tools/make_whale_skin_icons.py 可重建对应的 20 像素透明度图标。

40 亲密度的长袖睡衣戴鲸鱼头套。60 亲密度的家居服保留普通软兜帽，
去掉像眼睛的圆点和动物脸细节；同一皮肤各姿态保持一致。

衣橱显示顺序为女仆装、长袖睡衣、见习魔女、家居服。显示位置映射到固定皮肤标识，
对应解锁门槛分别为默认、40、20、60，已穿状态随皮肤标识保存。

见习魔女替换原卫衣，沿用已保存的皮肤标识及 20 亲密度门槛。服装方向参考《小魔女学园》，角色保持项目鲸鱼娘形象。
参考 https://mikatan.goodsmile.info/en/2017/03/13/nendoroid-atsuko-kagari-little-witch-academia/
魔女尖帽姿态单独预留互动台词空间。
