# v1.3.0 发布记录

[English](RELEASE-v1.3.0.md)

本版合并语音输入与会话列表改进，以及陪伴互动、状态声音和导航更新。社区审核状态以平台回执为准。

1. 新增语音输入：任务主页长按 ↑ 开始录音，边说边传；停止后在电脑本地转成文字，预览并确认后发送。
2. 会话列表只显示名称和彩色状态，优先展示待回答、未读错误和新回复。
3. 新增鲸鱼娘陪伴互动：打招呼、摸摸、喂小鱼、喝咖啡；空闲时自动进入，离线也能互动，有新工作或待处理事项时返回工作界面。
4. 新增不同状态的提示音和提示语音：完成、待选择、出错、蓝牙断开分别提醒；可切换音效／语音，默认语音，手动停止不提醒。
5. 优化任务主页与设置入口：长标题滚动，确认提示居中，列表可进入设备设置，长按确认增加进度提示。

Build：完整构建、0x0 合并布局和匹配 ELF 校验通过。Host tests：59 项应用测试、C 状态/音频/设置、跨语言回放、原生 LVGL 和插件打包通过。Device tests：用户已验收 dev1 功能及修正后的语音发送、dev2 导航；正式镜像仅变更版本号，未重新刷机。未验证：正式镜像实机重刷、跨页 BLE 定位、反复录音/播放、长期稳定性。
