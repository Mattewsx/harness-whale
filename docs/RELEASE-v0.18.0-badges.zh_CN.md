# 徽章饰品与逻辑重连

本修订基于已公开的待机陪伴版本。对应电脑组件请使用
`feature/desk-companion-upgrade` 分支，在解压目录运行：

```text
python installer/install_companion.py --non-interactive --skip-key
```

安装后重启 DSH。会话同步需要蓝牙，无需 Wi-Fi 配网。在主页进入互动，选择服饰或徽章；
↑↓ 浏览，确认穿戴已解锁项目，长按 ↑ 回主页。

## 变化

- 八枚成就徽章解锁四组饰品，与四套服装独立搭配，换装保留当前饰品。
- 小鲸鱼玩偶在主页和动作中持续显示；手臂忙碌时放在角色身旁。切换动作、服装时刷新旧、新饰品区域。
- 徽章进度及穿戴保存，支持 6、126、206 字节徽章记录。旧格式保留累计进度，但缺少完整题目身份，
  首次重放可能再计一次；当前格式保留完整协议身份，不承诺跨 epoch 的业务级去重。
- Windows 可直接定位已配对设备，不依赖重新广播。有效完整 HELLO 能重建逻辑协议会话，即使物理连接仍被保留；
  其他重复帧继续抑制。

## 验证与范围

Build 与 Host tests 通过：ESP-IDF 5.5.3 完整门禁、142 项 Python 回归、Python→C 回放、
324 组存档迁移和原生渲染检查。相同渲染输入的 720 次刷新对照零差异，LVGL 池峰值余量 5,960 字节，属于主机测量。

仅应用升级后，首次启动前分区/NVS/PHY 区域逐字节保留，运行 ELF 与交付物一致。
三轮逻辑重连分别为 2.890、2.766、2.766 秒，托管桥接器重启后也恢复通信。
用户已确认换装、动作显示及重启后睡衣和玩偶保留。以上不覆盖所有姿态的遮挡、真实休眠/唤醒、
音频/回复/保存并发内存峰值及长期稳定性。
