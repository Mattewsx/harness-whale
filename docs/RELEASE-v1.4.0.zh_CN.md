# v1.4.0 整合候选版

[English](RELEASE-v1.4.0.md) · **简体中文**

本候选版整合省电、续航记录修复、桌面时钟和协议 2.3 大帧，尚未正式发布。OTA 已排除，继续使用现有单应用分区，通过 USB 一起更新程序、图片和声音。

## 整合内容

1. 主页或陪伴页两分钟无操作，且全局工作摘要确认空闲（或电脑离线）时进入桌面摆件，显示大号时间、鲸鱼娘、日期和电量；23:00–07:00 使用暗色时钟布局。任意键返回主页，松手不继续触发主页操作；工作或待处理事项到来时返回相关任务或列表，不自动清除未读标记。
2. 保持两分钟调暗、五分钟息屏；断开电脑 30 秒后降低广播频率，离线十分钟且已息屏时深睡，定时醒来等待电脑，按键立即唤醒。详见 [省电说明](POWER.zh_CN.md)。
3. 电量累计回升会开始新一轮记录，持续充电不反复覆盖上一轮放电记录；电脑分析工具剔除新旧日志中的充电区间。仅凭电量无法识别百分比不变时的 USB 供电，续航测量仍须拔线。
4. 协议 2.3 协商最高 244 字节帧（MTU 247 时载荷 236 字节），兼容传统 20 字节帧；`/whale` 显示帧长和 MTU。优化针对命令和回复传输，麦克风音频沿用原通道。
5. 桥接器在首个快照完成后及每 30 分钟校准时间；深睡保留时钟，断电重启后需电脑重新校准。旧桥接器无法提供全局空闲状态，离线桌面摆件重连它后返回主页，仍可手动进入陪伴。

## 验证

Build：PASS，ESP-IDF 5.5.3 完整门禁、合并镜像与匹配调试归档校验通过。Host tests：PASS，99 项 Python 测试、固件原生测试、六组跨语言回放、LVGL 渲染、字体覆盖、Python 编译检查和插件打包通过。Windows 下部分依赖符号链接／POSIX 的基础设施测试跳过，整合源码尚未在 Linux CI 运行。Device tests：先前镜像 `48ec4027b3e8d0f8eaafc8066b0741722a738d1ff1795793b75cf7d1495ea935` 的基础实机验收通过。通过 USB 仅升级应用，保留 NVS；启动及自动蓝牙重连正常，已协商到 244 字节帧。用户确认屏幕与列表、最近回复阅读、录音识别后取消、空闲桌面时钟与时间、按键返回不连带触发、两分钟调暗及五分钟息屏唤醒正常。未验证：实测蓝牙吞吐、离线深睡及按键／定时唤醒、深睡时钟连续性、实机工作事件打断、本构建的真实语音发送和提示音播放、拔线续航与长期稳定性。下述新构建额外修复了充电中时钟重置后继续充电覆盖历史记录的问题，回归测试和完整构建门禁通过，但尚未刷入；此前实机结论不代表这一精确镜像已通过验收。本结论仅覆盖基础验收，尚未正式发布。

固件：`whale-v1.4.0`。使用配套电脑组件，安装后完全退出并重启 DSH。完整镜像从 `0x0` 刷写，可能清除配对和设置；核对设备布局兼容后，可通过 USB 在 `0x10000` 更新应用并保留 NVS。刷机须另行确认。
