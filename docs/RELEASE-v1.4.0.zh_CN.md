# v1.4.0 发布记录（候选）

[English](RELEASE-v1.4.0.md)

协议 2.3：通过协商大帧加快蓝牙传输。分区布局和界面不变。

1. 能力位 12 协商大帧。桥接器提供 `min(244, MTU − 3)`；固件取双方帧长、244 与自身 ATT MTU − 3 中的最小值。MTU 247 时每帧数据 236 字节，原先为 12 字节。
2. 大帧碎片使用帧版本 3；传统碎片仍为版本 2 并继续被接受。握手回复始终使用传统帧，断开后授予失效。
3. 双向兼容：v1.3.1 及更早固件忽略位 12，保持 20 字节帧；旧桥接器不会提供位 12，新固件按 2.2 原样回复。
4. 固件用 8 个 244 字节的环形槽（约 2 KB）按顺序接收大帧写入，事件队列格式不变。
5. `/whale` 显示协商后的 `BLE frame` 帧长与 MTU。
