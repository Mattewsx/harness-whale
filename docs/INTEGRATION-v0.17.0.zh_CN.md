# v0.17.0 本地整合

本次为未发布的开发整合，包含随机邀请，以及经审查的 PR #11（审批和多选）、#12（今日小结）、#13（语音新建任务）。不创建 GitHub Release，不提交社区审核。

## 审查修复

- 小结在首次蓝牙连接前及合并历史统计后保存；累计总数不随去重缓存淘汰而减少；桥接器 epoch 变化时清除旧摘要。较宽数字自动换成两行。
- 语音新任务先解析工作区，成功挂接后才发送第一条消息；创建结果不确定时保留录音标识回执，重试不重复新建。回执容量满时拒绝新增，不淘汰已记录的身份。
- 设备审批完整展示工具名、全部参数和权限理由，题干上限 512 字节，不能完整展示时交回电脑。换行等分隔符用 JSON 转义保留。等待电脑清理期间若取消或会话不可见，不再返回允许。
- DSH 兼容修正：设备审批监听包裹已有电脑审批器，完整保留原始理由并只选择一种界面译文，完整解析 JSON 字符串参数；本机诊断只提供请求数量。完整内容超限的请求继续在电脑处理。
- 富问题与语音新任务的能力位和控制消息同时保留，现有皮肤、亲密度额度、看过即清的角标及随机邀请规则保持有效。
