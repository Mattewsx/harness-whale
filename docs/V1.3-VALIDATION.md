## Post-flash voice incident (2026-11-06)

Two captured recordings reached the finish acknowledgement and the user saw recognized text. Delivery failed before `followup`: host activation returned `gateway/internal` because a local desktop preset still referenced `@deepseek-ai/dsh-tool-subagent-control/list-agents`. The installed host no longer exports that entry; its main control plugin already registers `list_agents`. Three obsolete duplicate preset entries were removed locally, retaining the main control entries and reversal metadata outside Git. The installer does not silently rewrite other users' presets.

The missing test session passed the installed host's native compression, storage identity and event-format validation. The controlled failed activation left its journal byte-identical to the private backup. After correcting the preset, host activation succeeded and the desktop visibly showed all four unarchived main sessions, the original five conversation turns, and an enabled composer. No text was automatically submitted or resent.

The source plugin now keeps receipt queries read-only, validates text and waiting state before activating a cold session, and suppresses repeated failed activation until the desktop makes that session live or the plugin restarts. Explicitly confirmed submits can use the host's native resolver. All 59 application host tests (including 15 voice tests) and plugin bundling pass, including failed activation and recovery. Temporary diagnostic probes and the emergency send block were removed from installed files; the runtime was reloaded and the desktop remained healthy. The user then confirmed successful device delivery, exactly one desktop message and a healthy session; four interactions, sound modes/preview, return and repeated recording also passed.

The original dev1 ZIP is unchanged and does not contain this later plugin revision. The later user acceptance applies to dev1 with the corrected installed plugin. Prolonged stability and the new dev2 navigation still require device testing; this is not formal release acceptance.
