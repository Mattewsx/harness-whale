# 鲸鱼模式省电与续航实测

[English](POWER.md) · **简体中文**

v1.4.0 起，鲸鱼模式在 v1.3 的“2 分钟调暗”之外增加三项省电行为。电脑端协议和插件不变（仍为 2.2）。

## 行为

| 情况 | 行为 |
| --- | --- |
| 无操作 2 分钟 | 背光调暗（同 v1.3） |
| 无操作 5 分钟 | 息屏：背光关闭，停止界面刷新；第一次按键只点亮屏幕 |
| 有任务运行、有待答问题、停在非主页的页面 | 保持亮屏（同 v1.3）；断开电脑后，旧的“运行中”不再算数 |
| 断开电脑 30 秒后 | 广播间隔从 30–60 ms 拉长到约 1.0–1.3 s；按键会恢复 30 秒快速广播 |
| 断开电脑累计 10 分钟且已息屏 | 进入离线深睡：任意键立即唤醒；另外每 10 分钟自动醒来，暗屏广播 75 秒等电脑重连，没等到就继续睡 |
| 连续 12 次自动醒来（约 2 小时）都没等到电脑 | 只保留按键唤醒 |

离线页面（读回复、语音页等）在 5 分钟无操作后会回到主页再进入息屏和深睡；配对、解绑过程中以及录音、播放提示音时不会睡。

深睡会重启应用：配对保留，内存里的回复缓存清空，与断电相同。按键唤醒后约 1 秒内的按键不会触发操作，避免把唤醒那一下当成点击。电量计在深睡时保持工作，以免每次醒来电量读数被重置。

桥接器的重连退避最长 60 秒、每次扫描 8 秒，75 秒的醒来窗口至少覆盖一次完整扫描；电脑回来后最迟约 10 分钟自动连上，按任意键可以立即连上。

## 实机测试

### 快速验证（台架版本）

用短阈值编译，几分钟内走完全部状态：

```bash
cd device-firmware
idf.py -D WHALE_POWER_TEST=1 build
```

台架版本：10 秒调暗、20 秒息屏、10 秒后慢速广播、断开 60 秒后深睡、醒来窗口 30 秒、每 60 秒自动醒来、3 次后只按键唤醒。启动日志会打印 `BENCH BUILD`，**不要发布这个镜像**。

串口里 `whale_power` 行记录每次状态变化和每 30 秒的状态（`boot`、`sleeps`、`cycles`、`screen`、`adv`、`offline_ms`、`soc`）；`whale_sleep` 行记录每次入睡的定时与周期数。建议检查：

1. 不动设备，观察 `screen=dim`→`screen=off`；按一次键只亮屏。
2. 关掉桥接器，观察 `advertising slow`，按键后恢复 `fast`。
3. 继续离线，观察 `offline sleep #1`，设备黑屏；按键应立刻醒来（`boot=key`）。
4. 再次入睡后不按键，等定时醒来（`boot=timer`，屏幕不亮）；在窗口内启动桥接器，应能重连并亮屏。
5. 深睡期间 USB 串口会断开，这是正常现象。

### 续航实测（正式版本）

USB 会给电池充电，所以续航必须拔掉 USB 测量。固件把每次电量百分比变化写入 NVS（时间用 RTC 秒，深睡期间继续计时），插回 USB 后读出：

1. 充满到 100%，拔掉 USB，按要测的场景使用（例如连着电脑正常工作，或一直离线）。电量回升 5 个点以上视为充过电，自动开始新一轮记录，上一轮保留。
2. 结束后（或设备没电关机后）插回 USB，运行：

   ```bash
   python harness/tools/whale_battery.py --serial COM5 --reset
   ```

   `--reset` 会让设备重启并打印记录；也可以手动按复位。结果给出耗时、电量下降、每小时耗电和按此推算的满电续航，以及连接、亮屏、离线醒来、慢速广播各自所占时间比例。`--log 文件` 可以分析保存下来的串口输出。

日志只含时间、电量和状态位，不含会话内容。电量计百分比本身有误差，建议每个场景至少测 20 个百分点以上再看推算值。
