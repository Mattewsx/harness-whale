# v1.3.0 development build

[简体中文](V1.3-IMPLEMENTATION.zh_CN.md)

Based on v1.2.0, on `feature/v1.3-companion-cues`. This is an unpublished development build; on-device acceptance remains required. The approved interaction and sound design is [V1.3-DESIGN](V1.3-DESIGN.md).

## Operation

- Task home: Up opens companion; hold Up records a voice reply; Down reads the latest reply. Confirm opens the list (or the current question). The Confirm hint is centered in the top bar; the footer is one line.
- Long home titles scroll automatically at about 22 px/s with 1.5-second end pauses. Short titles remain still. Full titles up to the existing 512-byte wire limit are fetched automatically, without consuming the voice shortcut.
- Companion: Up/Down select greeting, petting, feeding, coffee, or return. Confirm starts a three-second action. Hold Confirm interrupts and returns home; hold Down opens the list. Coffee finishes with “嗯，精神一点啦。” No counters, daily chores, or interaction speech.
- Open the list → Device settings → Sound reminders, or hold Confirm on home to open settings directly. Choose effects or voice; Confirm saves to NVS. Voice is the default. Preview uses the completion cue. Connection management and version information remain available.

## Behavior and compatibility

The bridge now negotiates capability bit 11. Control messages `0x50` (25 bytes, `<QIHHHHIB`) report epoch, last event sequence, total/running/waiting/unread counts, one running session ID, and complete-roster status. `0x51` (26 bytes, `<QIIIIBB`) reports epoch, event sequence, session, run, cue revision, current valid cue, and live trigger. Cue kinds are 1=choice, 2=error, 3=completion/reply, 4=local disconnect; trigger 5 is visual work start. Zero invalidates pending cues. `0x52` (`<QI`) seeks a session outside the cached list window. All are control-lane messages. Existing 2.2 framing and BLE services remain compatible.

Global state uses the same filtered, unarchived main-session roster as the list. Incomplete roster restoration cannot claim idle. Initial connection/reconnection is a silent baseline; history restoration never triggers speech. Old bridges retain manual companion but cannot trigger connected automatic companion. Auto entry is restricted to home after 120 seconds without input and no global work, waiting or unread items. Offline companion stays available. Auto navigation does not reset dimming time or clear unread markers.

Live work interrupts companion; new attention opens the priority list, while new work seeks its task home even outside the current page. Events carry invalidations for reads, deletion and new states. Sounds aggregate for one second in choice/error/completion/disconnect order. Manual stop and ordinary thinking/tool/network wait are silent. Disconnect must persist five seconds before aggregation. Reconnection cancels it. Recording interrupts queued/playing audio; deferred reminders are revalidated before playback.

One existing peripheral worker serializes battery I2C, codec playback, recording and codec sleep. PCM is streamed from Flash in 320-byte blocks; no runtime synthesis or cloud speech service is added. Effects use 85% volume and fixed voice assets use 80%; dev1 interaction/sound and repeat-recording acceptance was confirmed by the user. The eight sounds plus six poses and two coffee props occupy 898,922 bytes. LVGL remains 32 KiB; the recording worker remains 24 KiB.

## Validation and delivery

See the delivered validation report for exact build identity, checks, image hashes and ELF archive. Native rendering checks are not device screenshots. Device tests are not run until explicitly authorized. Pending: acoustic loudness, repeated recording/playback on hardware, BLE lifecycle and multi-page interruption, NVS persistence after actual restart, and long-duration animation stability.

Use the matching bridge source/package with the firmware. No GATT service change or re-pairing is expected for this extension. The merged image is for offset `0x0`; it may reset stored data. A compatible app-only upgrade at `0x10000` is supplied separately. Never flash the app image at `0x0`.

## dev2 navigation

The fixed settings row is separate from task selection and never clears unread markers. Up from the first cached task selects settings; Down returns to the first task. On later cache pages, Up from settings loads the previous page. Task paging and attention ordering remain intact. A manual list open selects the current session by identity (capable bridges locate it across pages); work interruptions select the priority list. Old bridges preserve the session if present in the refreshed window, otherwise select its first task. Empty/offline lists still expose settings.

Short Confirm acts on release. After 125 ms a home hold shows progress towards the BSP 500 ms long-press threshold; release before the threshold opens the list or current question. Long press enters settings once and consumes the release. A wake-only gesture or intervening page change cannot activate another page. Settings returns to its entry page, while sound/connection/version subpages return to settings.
