# 随机陪伴邀请

本地 v0.17.0 开发版中，鲸鱼娘会偶尔邀请你打招呼、摸摸、喂小鱼或喝咖啡。
主页仍是三个原有功能图标，默认选中会话，按键含义不变。

选左侧互动图标并确认，进入互动页后会默认选中邀请对应的动作，再按确认回应。
也可以选择其他动作。接受邀请时显示对应短句，沿用普通互动的奖励及每日额度；
仅出现邀请不会增加亲密度。

只有白天、完全亮屏的小房间会发起邀请。满足条件后随机等待 45～75 秒，
后续邀请间隔 8～15 分钟，连续两次会换一种互动。手动互动后也会至少安静八分钟，
再考虑新邀请。

连接电脑时，必须有新鲜的全局摘要，确认所有主会话均无运行任务、待回答问题和未读事项。
已连接但不能提供全局摘要的旧桥接器不自动发起邀请；离线小房间仍可互动。

邀请等待 20 秒。未回应时在小房间安静收尾三秒，再继续日常动作。
不扣亲密度、不播放声音，不重置调暗、息屏或桌面时钟计时。
新工作或待处理事项、配对、录音、调暗以及离开主页／互动流程都会取消邀请。
收到工作更新时，用户已主动开始的普通互动保持原行为，只撤下自动邀请。

实现复用现有四套服饰的姿态。邀请状态、冷却和文案变体只保存在内存中，
不新增 NVS 存档、模型请求、云端服务或协议能力。

验证覆盖模拟的全局／后台工作、接受和忽略、亲密度额度、录音互斥、省电计时、
毫秒计时回绕、所有服饰、台词间距及静态画面重复绘制。
主机测试和渲染预览不替代实机验收。
