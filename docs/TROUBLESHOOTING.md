# 排障

| 现象 | 检查 |
| --- | --- |
| `/whale` 显示 bridge offline | 完全退出并重启 DSH；确认 Python 和桥接器独立虚拟环境可用。 |
| 找不到设备 | 检查蓝牙、设备连接页、配对；关闭其他争用该设备 BLE 连接的程序。 |
| 会话数不一致 | 只统计未归档主会话；排除子代理。先检查 DSH 名单，再比较桥接器投影与设备快照。 |
| 没看到回复 | 打开任务主页后按 ↓；需要该会话已产生最终回复。不是每个中间思考片段都会显示。 |
| 回复仍显示旧版布局或页码 | 检查设备版本为 R10.1，确认写入了正确的应用或完整镜像。 |
| 重新展开仍需等待 | 首次读、新回复、重启桥接器、设备断电或缓存淘汰会触发读取；缓存不跨断电保存。 |
| 断线后长回复读不到后半段 | 仅已缓存内容可离线读，未读或已淘汰部分需要恢复 BLE。 |
| 不显示余额 | 本版设计为隐藏；无需配置 API Key。 |
| 不显示进度 | 只在有真实 Todo 数据时展示。 |
| 电池插线时变化很小 | 读数来自 CW2017，USB 供电时可长期保持较高电量；不代表续航测试。 |
| 中文显示替代符号 | 预编译固件包含 GB2312 一级汉字及固定 UI 文本，不保证所有扩展字符和 emoji。 |
| 固件校验失败 | 使用同一标签的源码、manifest 和附件；不要手改哈希绕过检查。 |

回复只包含最近一次最终回答，↑↓ 滚动的是同一条正文；旧回答不会保留导航入口。具体按键见 README。

记录问题时提供版本、现象与复现步骤，日志先删除真实会话、设备身份、凭据及本机路径。发生看门狗、崩溃或黑屏时，用该镜像对应的 ELF 解码；其他构建的 ELF 不可替代。不要因一次干净日志就声称长期稳定。
