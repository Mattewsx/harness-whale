## 安装、升级与复现

首次安装使用 [部署指南](AI_DEPLOYMENT.md) 的完整镜像，标准刷写器会整片擦除并写入 0x0。需要保留配对且布局相同的设备按 [UPGRADE](UPGRADE.md) 写应用镜像到 0x10000。

激活 ESP-IDF 5.5.3，在 `device-firmware/` 执行 `./tools/validate.sh`；在仓库根目录运行 README 中的电脑端测试和 `tests/firmware-replay/RUN.txt`。当前根目录 CI 验证 Windows/Linux 电脑端、固件静态与 C 回归、ESP-IDF 构建和 LVGL 渲染。只在全部要求的检查通过后合并和发布。

原始本机日志和用户会话不随包公开。预览图使用合成数据，历史 v0.09 标签与附件保持不变。
