# 语音术语校正

[English](VOICE-TERMS.md)

电脑插件在显示语音草稿前执行小范围文本校正。在“打开、启动、使用、重启”等
明确的中文产品操作词之后，将 `deep seek`、`deep sick`、`deepseek` 统一为
`DeepSeek`。单独的 `deep`、普通英文、引用内容、网址及带标识符后缀的内容保留。
这是识别后的文本校正，不是模型热词支持，也不是通用精度修复。特殊的命令式文本
仍可能有歧义，需要核对草稿后明确发送；发送内容与预览内容一致。

当前 DSH SenseVoice 接口没有热词参数。合成语音对比覆盖中文／自动／英文提示、
未压缩／20 kbit/s Opus 及 DSH 式 VAD 裁切，尚未证实稳定的通用改善。独立测试了
带 DEEPSEEK／HARNESS 热词的中英 Zipformer：英文样例改善，中英混合样例退步，
因此没有安装为运行时模型。不能据此替换当前识别器，或宣称真实麦克风精度通过。

本次只需重新加载电脑插件，无需刷机。识别语言、录音、蓝牙压缩、模型及确认发送
流程保持不变。回归覆盖 HTTP 预览、术语正反例和不会自动发送；真实麦克风效果
仍需验收。R11.4 固件及构建产物身份保持不变。
