# DeepSeek Harness 鲸鱼搭子 v1.2.0

[English](RELEASE-v1.2.0.md)

本次发行组合为 v1.2.0 电脑插件／桥接器和固件 `whale-R11.4-2.2`，协议 2.2。
固件沿用已通过构建门禁并完成短录音验收的原始 R11.4 二进制，未仅为发行版本改号重编译。

## 更新内容

- 任务主页长按 ↑ 直接开始语音录音，确认停止，核对识别文字后明确选择发送。
  录音边说边通过蓝牙传输，停止后在电脑本地识别；支持重录和取消。
- 会话列表只显示名称和彩色状态，待回答、未读错误、未读回复优先；查看对应内容后清除提醒。
- 任务主页突出鲸鱼娘、标题、状态和用时。最近回复连续滚动并缓存，只保留最近一次回复。
- 完成提示音为 85% 音量、150 毫秒；录音期间延后播放。
- 修复录音启动、编码栈和图形内存配置问题；明确中文操作语境中的 `deep sick` / `deep seek`
  可校正为 `DeepSeek`。这是有限的术语校正，不代表通用英文识别精度提升。

## 安装与升级

使用同标签源码或附件 `Harness-Whale-v1.2.0-companion.zip`，运行
`python installer/install_companion.py --non-interactive --skip-key`，完全退出重启 DSH。
在 DSH 启用本地 SenseVoice，等待模型准备完成。首次配对时核对并确认两端数字码。
旧版本缺少蓝牙音频服务时，按 [部署指南](AI_DEPLOYMENT.md) 两端解绑后重新配对。

首次刷写使用 `Harness-Whale-ESP32C3-8MB.bin`，偏移 **0x0**，可能清除配对与设置。
相同分区布局下的保留配对升级见 [UPGRADE](UPGRADE.md)：应用镜像只能写入 **0x10000**。
发布不授权自动刷机。
