Run from the repository root with a native C compiler (not the ESP cross compiler):

cc -std=c11 -Itests/firmware-replay/stubs -Idevice-firmware/main tests/firmware-replay/fw_replay.c device-firmware/main/whale_wire.c device-firmware/main/whale_reply_cache.c -o tests/firmware-replay/fw_replay.exe
python tests/firmware-replay/cross_replay.py

Python bridge frames drive the production C dispatcher and keys with hardware stubs.
The reply cache module is required. This test does not prove BLE radio or display timing.
